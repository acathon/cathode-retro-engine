IN THE REPOSITORY

Where things live

Engine core

crates/core/src

Framebuffer, ECS, renderer, raycaster, palettes, physics, pathfinding, netcode.

TypeScript SDK

packages/sdk/src

The API you write games against, plus the built-in font and the WebAssembly boot.

Card game layer

packages/cards/src

Deck, shoe, bankroll, generated card art and a pooled table renderer.

Cathode Studio

packages/studio/src

Scene tree, inspector, block language, pixel sprite editor, sound maker and tile level designer.

Native runtime

crates/platform-native/src

A desktop window with a GPU blit, audio and gamepad support, running the same core.

Headless checks

scripts/verify

Browser checks that assert what a unit test cannot: that a game boots, draws, and answers a d-pad.
